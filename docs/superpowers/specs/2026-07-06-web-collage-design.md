# 图片拼图网页版设计

## 目标

将 Windows 版“戌無图片拼图”完整迁移为可通过 GitHub Pages 使用的网页应用。所有图片只在浏览器本地处理，不上传服务器。

## 界面

桌面端沿用三栏结构：左侧导入与排序，中间实时画布，右侧设置与下载。视觉采用真白面板、冷灰工作区、蓝色强调色、紧凑的桌面工具布局。移动端按顶部操作、画布、图片列表、设置的顺序纵向排列。

## 功能

- 导入或拖入 1–6 张 JPG、PNG、WebP 等浏览器支持的图片。
- 图片选择、删除、清空、上移、下移。
- 1:1、3:4、9:16、2:3、4:3、3:2、16:9 画布比例。
- 随图片数量提供均分和不对称拼图模板。
- 间隙、抗锯齿圆角、背景颜色实时预览。
- 每张图片可独立上下左右调整格内取景并一键居中。
- 1600、2400、3200、4096 像素长边，PNG/JPG/WebP 下载。
- 图片对象 URL 在删除和页面卸载时释放，避免浏览器内存泄漏。

## 技术

React + Vite 构建界面，HTML Canvas 2D 统一负责预览与导出。布局与取景算法为独立纯函数并使用 Vitest 测试。GitHub Actions 构建并部署到 GitHub Pages。
