# Windows 图片拼图软件设计

## 目标

制作一款 Win10 x64 可用的离线图片拼图工具。界面延续现有“图片加水印”软件的左侧导入、中间预览、右侧设置结构；拼图能力参考用户提供的两张截图。

## 功能

- 导入多张 JPG、JPEG、PNG、WebP、BMP、TIFF；支持多选、文件夹拖放、移除、清空。
- 左侧显示缩略图和尺寸，并支持上移、下移改变拼图顺序。
- 支持 1:1、3:4、4:3、2:3、3:2、9:16、16:9 画布比例。
- 按图片数量提供 1 至 6 图模板，包括均分、主图加侧栏、主图加底栏、非对称网格。
- 间隙 0–80 像素、圆角 0–80 像素，均由拉杆实时控制。
- 背景色支持白、黑、浅灰和自定义颜色；图片使用居中填充裁切。
- 导出 JPG、PNG、WebP，提供常用长边尺寸与自定义宽高；可选择并打开导出位置。
- 设置本机保存；处理完全离线，不修改原图。
- 选中任意图片后可进入“调整图片位置”，通过上下左右方向键移动格内取景，并可一键居中；每张图片独立保存偏移，预览与导出一致。

## 架构

- `ImageCollage.Core`：比例、模板定义、布局计算、导出尺寸规则，可独立单元测试。
- `ImageCollage.App`：WPF 三栏界面、文件导入、预览、排序和设置持久化。
- `CollageRenderer`：ImageSharp 渲染服务，预览与导出共享同一布局计算，保证所见即所得。
- `installer`：Inno Setup 脚本；Windows 构建脚本先发布 self-contained x64 程序，再生成安装包（若构建机安装 Inno Setup）。

## 交互与错误处理

未导入图片时中间显示拖放提示，导出按钮禁用。模板会按当前图片数量过滤；更换比例、模板、间隙、圆角或背景时立即刷新预览。无法读取的文件逐个跳过并在状态栏说明；导出失败显示明确错误，不中断原图。

## 验证

核心测试覆盖比例、模板格子数量、边界归一化、间隙收缩和导出尺寸。应用通过 Release 编译、单元测试、Windows x64 publish 和发布产物检查。
